# Timberline Lodge — live cam wall

**👉 Live site: https://dkiiv.github.io/timberline-cams/**

Single-file page. Polls the public timberlinelodge.com snowcam JPEGs (~20s cadence), buffers frames, timelapse scrubber. No build step.

The resort publishes still frames only — no HLS/RTSP/video endpoint exists publicly — so this wall is the closest thing to a live feed: ~3 fps across all 8 cams (Lodge, Pucci, Magic Mile, Jeff Flood, Palmer/Silcox, Cascades/Bruno's, Snow Stake, Summit Pass).
